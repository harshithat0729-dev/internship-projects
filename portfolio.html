A little about how I work

I like small, well-structured pieces of code that do one thing properly.

The short version

I work mostly with HTML, CSS and vanilla JavaScript, and I care about the details people feel rather than notice: keyboard support, sensible focus states, layouts that don't break at 360px, and animations that stay out of the way. I'm currently building out my internship project set and learning more about the React ecosystem.
